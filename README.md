# RoyalDuel Bot

**TON Rolls PvP** — Красивое PvP колесо рулетки на TON.

## Структура

- `client/` — Telegram Mini App (React + TypeScript + Tailwind)
- `server/` — Будет позже (Node.js + Socket.io)

## Как запустить Frontend локально

1. Перейди в папку `client`
2. `npm install`
3. `npm run dev`

Открывается на `http://localhost:5173`
